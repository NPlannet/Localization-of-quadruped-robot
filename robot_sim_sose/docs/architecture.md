# Project Architecture

This repository separates reusable ROS 2 code from operating scripts, recorded
data, generated results, and third-party drivers.

## Data flow

```text
XGO controller ──> xgo_driver_bridge ──> /imu/data, /odom, odom -> base_link
                                        ^
                                        └── /cmd_vel (optional motion control)

LD19 LiDAR ──> /scan ──> dynamic_scan_filter ──> /scan_filtered
                    └──────────────┬───────────────┘
                                   v
                    SLAM Toolbox / Cartographer / RTAB-Map
                                   |
                                   v
                              map -> odom, /map

camera_ros ──> /camera/image_raw + /camera/camera_info ──> RTAB-Map/Foxglove
```

The mapper consumes either `/scan` or `/scan_filtered`. The filter never
overwrites the raw scan, which makes paired comparisons possible.

## Coordinate frames

- `map`: globally corrected frame published by the selected SLAM system.
- `odom`: locally continuous frame calculated by the XGO bridge. Its position
  is integrated from applied velocity and its heading is corrected with XGO
  orientation registers.
- `base_link`: robot body frame.
- LiDAR and camera frames: fixed sensor frames below `base_link`.

The central transform chain is `map -> odom -> base_link -> sensor`. A missing
link prevents scans from being placed in the map even when the robot appears to
move in another RViz frame.

## Directory ownership

| Directory | Contents |
| --- | --- |
| `src/` | Project-owned ROS 2 packages |
| `third_party/` | Vendored external packages, currently the LDROBOT driver |
| `scripts/` | User-facing build, sync, run, record, monitor, and plot commands |
| `docs/` | Task-focused guides |
| `evaluation/datasets/` | Input bags and waypoint sidecars |
| `evaluation/results/` | Metrics, maps, databases, and plots worth retaining |
| `evaluation/runs/` | Temporary output from new physical-robot recordings |

Build products (`build/`, `install/`, and `log/`) are generated by colcon and
are not source code.

## ROS packages

- `xgo_description`: URDF, Gazebo worlds, RViz, offline odometry/evaluation,
  and bag-replay launch files.
- `xgo_driver_bridge`: physical XGO controller bridge and unified robot
  bringup, including live mapper selection.
- `dynamic_scan_filter`: temporal cluster tracking and dynamic-return removal.
- `nav2_wfd`: wavefront-frontier exploration behavior.
- `yolo_detector`: optional camera detection experiment.
- `ldlidar_stl_ros2`: external LD19 driver stored under `third_party/`.

## Runtime modes

Simulation uses `xgo_description/simulation.launch.py`. Offline experiments use
one of the three `bag_replay*.launch.py` files. The physical robot uses
`xgo_driver_bridge/robot_sensor_bringup.launch.py`; its `slam_method` argument
selects `none`, `slam_toolbox`, `cartographer`, or `rtabmap` without changing
the sensor stack.
